## Start time ~5:30 PST
## End time ~6:01 PST

## Running locally
Requires Node.js 22.22+ (includes npm). Nothing else to install.
```bash
npm install
npm run dev
```
Then open http://localhost:5173. `npm run dev` keeps running, so use a second terminal for the checks:
```bash
npm test
npm run lint
```
